# Transora signed tutoring research prototype

No trained checkpoints or datasets are included. Generated motion is experimental. The learner input is camera video; successful responses contain only a 12-fps pose sequence. The browser renders a skeleton. Each question is standalone. The coding component uses an existing local Ollama model; the two motion networks initialize from scratch.

1. Install Python 3.11 in a virtual environment and run `python -m pip install -r requirements.txt`. CUDA-enabled PyTorch is optional.
2. Obtain sentence-level clips and their matching transcripts from the original research releases: https://exploration-lab.github.io/iSign/ and https://how2sign.github.io/. Follow their terms. Use segmented clips, not entire source videos. Include signed coding questions AND fluent signed explanations with accurate transcripts for your intended topics. Neither corpus is a curated programming course.
3. Create a UTF-8 CSV with header `language,split,signer,video,text`. Each row identifies one clip, its verified signer ID, a video path relative to the CSV, and its English translation. Quote transcripts containing commas. Use ASL or ISL and train or validation. Reserve an additional signer-disjoint test set. Never infer signer identity from row numbers.
4. Run `python train.py corpus.csv ISL` and separately `python train.py corpus.csv ASL`. The trainer extracts landmarks, caches them beside the manifest, optimizes sign-to-text and text-to-motion, and saves the best validation checkpoint for each language in the working directory. Single-utterance training is a baseline for experiments; large runs require benchmarking and batching. Keep checkpoint and app processes in the same working directory.
5. Install Ollama, run its local service and `ollama pull qwen2.5-coder:3b`. Set TUTOR_MODEL to select another installed model. Run `python -m uvicorn app:app --host 127.0.0.1 --port 8090`. Open http://127.0.0.1:8090 and record a question.
6. TransoraPlus can mount the included page in an iframe on localhost with camera permission, or send a multipart POST with field video to /ask/ISL?course=Python on a same-origin proxy. The response contains frames[time][joint][x,y,z] and fps. app.py reports missing checkpoints, unreadable hands, unsupported words and tutor outages explicitly.
7. Before using with learners, measure sign-to-text quality on held-out signers and have fluent ASL and ISL reviewers independently interpret generated answers without seeing the source text. Measure answer correctness and how often incorrect input passes rejection. Teacher-forced validation loss and a running avatar do not establish comprehension. This baseline has no calibrated semantic-confidence score or discourse memory.
